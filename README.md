# Bug Bounty Search Engine

A simple browser-based Google Dork tool for bug bounty hunters. Enter a target domain, click a technique, and it opens the search in Google.

## How to use

1. Open `bug-bounty.html` in your browser
2. Type the target domain (e.g. `example.com`)
3. Click any button — it opens the dork query in a new tab

## What's included

75 dorks across recon, exposed files, vulnerabilities, WordPress, login panels, credentials, API endpoints, and more.

## Note

Only use on domains you have permission to test.
